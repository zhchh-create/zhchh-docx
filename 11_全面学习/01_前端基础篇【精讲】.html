1HTML 基础与语义化

1.1 HTML文档结构

一个标准HTML文档的骨架，浏览器从上到下逐层解析渲染。

HTML文档树结构

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>页面标题</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>头部</header>
  <main>主体内容</main>
  <footer>底部</footer>
  <script src="app.js"></script>
</body>
</html>

1.2 语义化标签

用正确的标签表达内容含义，而不是全用div+css。

常见语义标签布局示意

  • header：页面或区块的头部
  • nav：导航链接容器
  • main：页面主体内容（每页唯一）
  • article：独立完整的内容单元（文章、博客、卡片）
  • section：文档中的一个章节
  • aside：侧边栏、相关内容
  • footer：页面或区块的底部
✅ 语义化好处：SEO更好、无障碍读屏友好、代码可读性高、失去CSS后仍有结构。

2CSS 核心布局与样式

2.1 选择器与优先级

CSS优先级层级

/* 常用选择器 */
* {}                    /* 通配符 */
div {}                  /* 标签选择器 */
.box {}                 /* 类选择器 */
#header {}              /* ID选择器 */
.box p {}               /* 后代选择器 */
.box > p {}             /* 直接子元素 */
.box + p {}             /* 相邻兄弟 */
.box:hover {}           /* 伪类 */
.box::before {}         /* 伪元素 */
[type="text"] {}        /* 属性选择器 */
.box1, .box2 {}         /* 分组 */

2.2 盒模型

标准盒模型（box-sizing: content-box）

/* 两种盒模型 */
.box {
  /* 默认：宽高只算content，padding和border会撑大盒子 */
  box-sizing: content-box;
  
  /* 推荐：宽高包含content+padding+border，计算更直观 */
  box-sizing: border-box;
}
💡 现代项目一般全局设置 * { box-sizing: border-box; }，布局计算更省心。

2.3 定位机制

  • static：默认，正常文档流
  • relative：相对定位，相对于自己原来的位置偏移，不脱离文档流
  • absolute：绝对定位，相对于最近的非static父元素定位，脱离文档流
  • fixed：固定定位，相对于浏览器窗口，滚动不移动
  • sticky：粘性定位，滚动到阈值后固定（吸顶效果）
/* 吸顶导航 */
.sticky-nav {
  position: sticky;
  top: 0;
  z-index: 100;
}

/* 悬浮返回顶部 */
.back-top {
  position: fixed;
  right: 20px;
  bottom: 20px;
}

2.4 Flexbox 弹性布局

Flex布局主轴方向

.container {
  display: flex;
  
  /* 主轴方向 */
  flex-direction: row; /* row / row-reverse / column / column-reverse */
  
  /* 主轴对齐 */
  justify-content: flex-start; /* flex-start / center / flex-end / space-between / space-around */
  
  /* 交叉轴对齐 */
  align-items: stretch; /* flex-start / center / flex-end / stretch */
  
  /* 多行时行间距 */
  align-content: center;
}

.item {
  flex: 1; /* 占剩余空间比例 */
  flex-shrink: 0; /* 不收缩 */
}

2.5 Grid 网格布局

.container {
  display: grid;
  
  /* 定义列：3列，每列1fr */
  grid-template-columns: 1fr 1fr 1fr;
  
  /* 行高自动 */
  grid-auto-rows: 100px;
  
  /* 间距 */
  gap: 16px;
}

/* 常用：12栅格 */
.card {
  grid-column: span 4; /* 占4列 */
}

2.6 居中方案大全

/* 1. Flex居中（最常用） */
.parent {
  display: flex;
  justify-content: center;  /* 水平 */
  align-items: center;       /* 垂直 */
}

/* 2. Grid居中 */
.parent {
  display: grid;
  place-items: center;
}

/* 3. 绝对定位 + transform */
.child {
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}

/* 4. 文本水平居中 */
.text {
  text-align: center;
  line-height: 单倍行高; /* 垂直居中单行 */
}

2.7 响应式设计

/* 移动端优先 */
.box {
  width: 100%;
  padding: 10px;
}

/* 平板以上 */
@media (min-width: 768px) {
  .box { width: 750px; }
}

/* 桌面以上 */
@media (min-width: 1024px) {
  .box { width: 960px; }
}

/* 断点参考：
   < 768px   手机
   768-1023  平板
   >=1024    桌面 */

2.8 动画与过渡

/* 过渡：状态平滑变化 */
.btn {
  transition: all 0.3s ease;
}
.btn:hover {
  background: #1d4ed8;
  transform: translateY(-2px);
}

/* 关键帧动画 */

  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }

}

3JavaScript 核心概念

3.1 数据类型

JS数据类型分类

// 原始类型：赋值拷贝，存的是值
let a = 10;
let b = a;
b = 20;
console.log(a); // 10，互不影响

// 引用类型：赋值拷贝的是地址，指向同一个对象
let obj1 = { name: '张三' };
let obj2 = obj1;
obj2.name = '李四';
console.log(obj1.name); // 李四，都改了

// 类型判断
typeof 123;        // 'number'
typeof 'abc';      // 'string'
typeof null;      // 'object' (历史bug)
Array.isArray([]); // true

3.2 作用域与闭包

作用域链层级

// 闭包：函数 + 它能访问的外部变量
function createCounter() {
  let count = 0;  // 私有变量，外部访问不到
  
  return function() {
    count++;
    return count;
  };
}

const counter = createCounter();
counter(); // 1
counter(); // 2
counter(); // 3
// count被闭包保存在内存中，不会被回收
💡 闭包用途：私有变量、函数工厂、防抖节流、柯里化。

3.3 this 指向规则

// this指向谁，看函数怎么调用，不看在哪定义

// 1. 全局调用：this = window（浏览器）
function show() { console.log(this); }
show(); // window

// 2. 对象方法调用：this = 调用者
const obj = {
  name: '张三',
  say() { console.log(this.name); }
};
obj.say(); // 张三（this是obj）

// 3. call/apply/bind：手动指定this
function greet() { console.log(this.name); }
const person = { name: '李四' };
greet.call(person); // 李四

// 4. 箭头函数：没有自己的this，继承外层的this
const arrow = () => console.log(this);
// 箭头函数的this在定义时就定了，不会变

3.4 原型与原型链

原型链查找路径

class Person {
  constructor(name) {
    this.name = name;
  }
  sayHi() {
    console.log('你好，' + this.name);
  }
}

const p1 = new Person('张三');
p1.sayHi(); // 你好，张三

// p1本身没有sayHi方法，沿着__proto__找到Person.prototype上的方法
// 这就是原型链继承

3.5 事件循环（Event Loop）

事件循环执行模型

console.log('1'); // 同步

setTimeout(() => {
  console.log('2'); // 宏任务
}, 0);

Promise.resolve().then(() => {
  console.log('3'); // 微任务
});

console.log('4'); // 同步

// 输出顺序：1 → 4 → 3 → 2

3.6 Promise 与异步编程

Promise三种状态

// 基本用法
const request = new Promise((resolve, reject) => {
  // 异步操作
  setTimeout(() => {
    const success = true;
    if (success) {
      resolve({ code: 200, data: '成功' });
    } else {
      reject(new Error('失败'));
    }
  }, 1000);
});

// 链式调用
request
  .then(res => { console.log(res); return res.data; })
  .then(data => { console.log(data); })
  .catch(err => { console.error(err); })
  .finally(() => { console.log('结束'); });

// async/await 写法（更简洁）
async function fetchData() {
  try {
    const res = await request;
    console.log(res);
  } catch (err) {
    console.error(err);
  }
}

5HTTP 网络协议基础

5.1 请求响应模型

HTTP请求-响应模型

// 请求
GET /api/users HTTP/1.1
Host: example.com
Cookie: session=abc123
Content-Type: application/json

// 响应
HTTP/1.1 200 OK
Content-Type: application/json
Set-Cookie: token=xyz789

{ "code": 200, "data": [...] }

5.2 常见状态码

// 2xx 成功
200 OK          // 请求成功
201 Created     // 创建成功（POST新建资源）
204 No Content // 成功但无返回内容（如删除）

// 3xx 重定向
301 Moved Permanently  // 永久重定向
302 Found              // 临时重定向
304 Not Modified      // 资源未修改，用缓存

// 4xx 客户端错误
400 Bad Request        // 请求参数错误
401 Unauthorized       // 未登录/未认证
403 Forbidden         // 已登录但无权限
404 Not Found         // 资源不存在
429 Too Many Requests // 请求太频繁，被限流

// 5xx 服务端错误
500 Internal Server Error // 服务器内部错误
502 Bad Gateway           // 网关错误
503 Service Unavailable    // 服务不可用
504 Gateway Timeout        // 网关超时

5.3 跨域与CORS

浏览器的同源策略：协议+域名+端口，三者有一个不同就是跨域。

同源策略示意

// 服务端设置CORS响应头
response.setHeader('Access-Control-Allow-Origin', '*');
response.setHeader('Access-Control-Allow-Methods', 'GET, POST, PUT, DELETE');
response.setHeader('Access-Control-Allow-Headers', 'Content-Type, Authorization');

6TypeScript 入门

6.1 基础类型与接口

// 基础类型
let name: string = '张三';
let age: number = 25;
let isStudent: boolean = true;
let hobbies: string[] = ['读书', '跑步'];
let u: undefined = undefined;
let n: null = null;

// 接口：定义对象结构
interface User {
  id: number;
  name: string;
  age?: number;  // 可选属性
  readonly createTime: Date;  // 只读
}

const user: User = {
  id: 1,
  name: '李四',
  createTime: new Date()
};

// 函数类型
function greet(user: User): string {
  return `你好，${user.name}`;
}

6.2 泛型

// 泛型：复用逻辑，类型也参数化
function identity(arg: T): T {
  return arg;
}

identity(123);   // 返回number
identity('abc');   // 返回string

// 泛型接口
interface ApiResponse {
  code: number;
  data: T;
  message: string;
}

// 泛型约束：要求T必须有length属性
function getLength(arg: T): number {
  return arg.length;
}
