2基础层 · 入门必备 基础

这一层是前端入门的最低要求，看完就能写出第一个网页。

2.1 HTML 文档结构 基础

HTML 是网页的骨架，浏览器从上到下解析标签，渲染出页面。

  • DOCTYPE：声明HTML版本，告诉浏览器用标准模式渲染
  • head：元信息，不显示在页面上（编码、标题、CSS、SEO）
  • body：页面所有可见内容都写在这里
  • 标签成对：开始标签<div>和结束标签</div>；空标签如<img><br>不需要闭合
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个页面</title>
</head>
<body>
  <h1>Hello World</h1>
  <p>这是我的第一个网页</p>
</body>
</html>

2.2 CSS 选择器与基本样式 基础

CSS 给HTML化妆：选择器找到元素，然后设置样式属性。

  • 标签选择器：div { } 选中所有div
  • 类选择器：.box { } 选中class="box"的元素（最常用）
  • ID选择器：#header { } 选中id="header"的元素（全局唯一）
  • 常用属性：color文字颜色、font-size字号、background背景、margin外边距、padding内边距
/* 选择页面上的元素 */
h1 {
  color: #1d4ed8;      /* 文字颜色蓝色 */
  font-size: 28px;    /* 字号28像素 */
  text-align: center; /* 文字居中 */
}

.card {
  background: white;  /* 背景白色 */
  padding: 20px;      /* 内边距20px */
  border-radius: 8px; /* 圆角 */
}

2.3 JavaScript 变量与数据类型 基础

JS 让网页动起来：存数据、做判断、处理交互。

  • 声明变量：let 声明可变变量，const 声明常量（推荐默认用const）
  • 基本类型：数字number、字符串string、布尔boolean（true/false）
  • 打印调试：console.log() 在控制台输出
  • 注释：// 单行注释，/* 多行注释 */
// 声明变量
const name = '张三';    // 字符串，用引号包起来
let age = 25;           // 数字，不用引号
const isStudent = true; // 布尔值：true 或 false

// 打印
console.log('姓名：', name);
console.log('年龄：', age);

// 简单运算
age = age + 1;
console.log('明年：', age);

3标准层 · 日常开发 标准

这一层是实际工作中每天都要用的技能，掌握后就能独立写业务页面。

3.1 Flexbox 弹性布局 标准

Flex 是一维布局方案，用来处理一行或一列的排列对齐，替代传统的float hack。

  • 容器设置 display:flex：开启弹性布局
  • 主轴对齐 justify-content：flex-start左对齐 / center居中 / space-between两端对齐
  • 交叉轴对齐 align-items：stretch拉伸 / center居中 / flex-start顶对齐
  • 间距 gap：子元素之间的间距，不用margin了
.container {
  display: flex;
  justify-content: space-between; /* 两端对齐 */
  align-items: center;            /* 垂直居中 */
  gap: 16px;                       /* 子元素间距16px */
}

.item {
  flex: 1; /* 占剩余空间的比例 */
}

3.2 DOM 操作与事件绑定 标准

JS 通过DOM API操作页面元素：找到元素、改内容、绑事件。

  • 找元素：document.querySelector('.box') 或 getElementById
  • 改内容：element.textContent = '新文字'，element.style.color = 'red'
  • 绑事件：element.addEventListener('click', 处理函数)
  • 事件对象 e：拿到鼠标位置、按键信息等
// 找到按钮
const btn = document.querySelector('#submitBtn');

// 绑定点击事件
btn.addEventListener('click', function(e) {
  console.log('按钮被点击了');
  
  // 找到显示区域，改内容
  const result = document.querySelector('#result');
  result.textContent = '你好，欢迎！';
  result.style.color = 'green';
});

3.3 Fetch 网络请求 标准

前端通过HTTP请求从后端拿数据，Fetch是浏览器内置的请求API。

  • GET 请求：拿数据，参数放在URL里
  • POST 请求：提交数据，参数放在请求体里
  • async/await：用同步的写法写异步代码，比.then()更清晰
  • 错误处理：用try/catch捕获异常
// GET 请求拿用户列表
async function fetchUsers() {
  try {
    const res = await fetch('/api/users');
    const data = await res.json(); // 解析JSON
    console.log('用户列表：', data);
  } catch (err) {
    console.error('请求失败：', err);
  }
}

// POST 提交表单
async function login(username, password) {
  const res = await fetch('/api/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ username, password })
  });
  return res.json();
}

3.4 本地存储 localStorage 标准

把数据存在浏览器本地，刷新页面也不丢。

  • 存数据：localStorage.setItem('key', 'value')
  • 取数据：localStorage.getItem('key')
  • 删数据：localStorage.removeItem('key')
  • 注意：只能存字符串，对象要先JSON.stringify
// 存token（登录后）
localStorage.setItem('token', 'abc123xyz');

// 取token（每次请求带上）
const token = localStorage.getItem('token');

// 存对象
const user = { name: '张三', id: 1 };
localStorage.setItem('user', JSON.stringify(user));

// 取对象
const savedUser = JSON.parse(localStorage.getItem('user'));

4深入层 · 原理进阶 深入

这一层是理解底层运行机制，遇到bug能定位、能优化性能、能写出更可靠的代码。

4.1 原型链与继承 深入

JS 没有类的传统继承，靠原型链实现属性查找：对象找不到属性，就沿着 __proto__ 往上找。

  • 每个对象都有 __proto__：指向它的构造函数的 prototype
  • 查找规则：实例 → 构造函数.prototype → Object.prototype → null
  • class 语法糖：ES6的class本质还是原型继承，只是写起来更像面向对象
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    console.log(this.name + '会叫');
  }
}

// 继承
class Dog extends Animal {
  speak() {
    console.log(this.name + '汪汪汪');
  }
}

const dog = new Dog('旺财');
dog.speak(); // 旺财汪汪汪

4.2 事件循环（Event Loop）深入

JS 是单线程的，为什么能处理异步？靠事件循环：把异步任务放到队列里，等同步代码执行完再依次处理。

  • 同步任务：在调用栈上立刻执行
  • 微任务：Promise.then、MutationObserver，优先级高，栈清空就立刻执行
  • 宏任务：setTimeout、setInterval、I/O，每次只取一个，然后又清空微任务队列
console.log('1'); // 同步

setTimeout(() => console.log('2'), 0); // 宏任务

Promise.resolve().then(() => console.log('3')); // 微任务

console.log('4'); // 同步

// 输出顺序：1 → 4 → 3 → 2

4.3 闭包（Closure）深入

函数 + 它能访问的外部变量 = 闭包。内部函数记住了外部作用域，即使外部函数已经执行完了。

  • 核心作用：创建私有变量、函数工厂、防抖节流
  • 注意点：闭包会持有变量引用，用多了可能内存泄漏
// 闭包实现计数器：count是私有变量，外部访问不到
function createCounter() {
  let count = 0; // 私有
  
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count
  };
}

const counter = createCounter();
counter.increment(); // 1
counter.increment(); // 2
console.log(counter.getCount()); // 2

4.4 浏览器缓存机制 深入

浏览器把静态资源存在本地，下次不用再下载，加快页面加载。

  • 强缓存：Cache-Control / Expires，直接用本地缓存，不发请求
  • 协商缓存：ETag / Last-Modified，问服务器资源变了没，没变就返回304
  • 应用场景：JS/CSS/图片等带hash的文件用强缓存，HTML用协商缓存

6常见误区与实战要点

新手常踩的坑：
  • CSS优先级搞不清：以为后写的就一定覆盖，忽略了选择器权重（ID > 类 > 标签）
  • 闭包变量被共享：循环里用var声明变量，导致所有回调拿到的都是最后一个值
  • 异步顺序搞反：以为setTimeout(0)会马上执行，其实它是宏任务，比Promise慢
  • 跨域不知道是谁的限制：不是后端拒绝，是浏览器的同源策略拦下来了
  • localStorage存对象不序列化：直接存对象，取出来是"[object Object]"
✅ 实战建议：基础层不用想太多，先照着写出来；标准层要练熟，形成肌肉记忆；深入层结合实际bug去理解，不要死背概念。
