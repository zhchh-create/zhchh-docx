HTML 语义化与文档结构

语义化不是为了好看，而是让结构本身携带含义——选择标签依据内容是什么，而非它长什么样。

  • 常用语义标签：header/nav/main/section/article/aside/footer
  • 语义化带来：SEO 结构化、无障碍读屏、代码可维护性
  • 失去 CSS 后，页面仍然是一篇有结构的文章

CSS 盒模型与布局

元素是 content→padding→border→margin 四层矩形；box-sizing 决定 width 到底含不含 padding/border。

  • 标准盒模型：width 只算 content
  • border-box：width 含 content+padding+border（工程惯例全局 reset）
  • Flex 一维布局、Grid 二维布局，替代 float hack
* {
  box-sizing: border-box; /* 全局统一 */
}

.container {
  display: flex;
  gap: 16px;
}
.grid-layout {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

JavaScript 核心概念

JS 的难不在语法，而在一套与多数后端语言不同的执行模型：动态类型、词法作用域、函数即对象、原型继承、闭包。

  • 作用域链：词法作用域，函数定义时就确定
  • 闭包：函数捕获词法环境，内部函数可以访问外部变量
  • 原型链：每个对象有 __proto__，指向构造函数的 prototype
  • this 指向：普通函数看调用者，箭头函数继承外层
// 闭包示例
function createCounter() {
  let count = 0;  // 私有变量
  return {
    increment: () => ++count,
    getCount: () => count
  };
}
const counter = createCounter();
counter.increment(); // 1

异步编程与事件循环

JS 是单线程的，靠事件循环处理异步任务：同步代码先执行，微任务清空后再执行宏任务。

  • 宏任务：setTimeout、setInterval、I/O、UI 渲染
  • 微任务：Promise.then/catch/finally、queueMicrotask
  • 执行顺序：同步 → 微任务(全部) → 宏任务(一个) → 渲染 → 下一轮
console.log('1'); // 同步

setTimeout(() => console.log('2')); // 宏任务

Promise.resolve().then(() => console.log('3')); // 微任务

console.log('4'); // 同步

// 输出顺序：1 → 4 → 3 → 2

TypeScript 类型系统

TypeScript 是 JS 的超集，添加静态类型。类型不是限制，而是文档——让代码自带说明。

  • 基础类型：string/number/boolean/array/tuple/enum
  • 接口 interface：描述对象结构，可继承
  • 泛型：让组件可复用，同时保持类型安全
  • 类型推导：不用每次都显式标注，TS 会自动推断
interface User {
  id: number;
  name: string;
  email?: string; // 可选
}

function getUser(url: string): Promise {
  return fetch(url).then(r => r.json());
}

getUser('/api/user/1').then(user => {
  console.log(user.name); // 有类型提示
});

HTTP 与跨域

HTTP 是浏览器和服务器之间的通信协议；跨域是浏览器的同源策略限制。

  • HTTP 方法：GET/POST/PUT/DELETE，语义化
  • 状态码：2xx成功、3xx重定向、4xx客户端错误、5xx服务端错误
  • 跨域方案：CORS（后端配置）、Nginx反向代理、JSONP
// 后端 CORS 中间件示例
app.use((req, res, next) => {
  res.header('Access-Control-Allow-Origin', '*');
  res.header('Access-Control-Allow-Methods', 'GET,POST,PUT,DELETE');
  res.header('Access-Control-Allow-Headers', 'Content-Type, Authorization');
  next();
});

4常见误区与实战要点

常见误区：
  • 把 CSS 当样式表写，忽略语义化——重构时才发现结构全乱了
  • JS 异步顺序搞不清，以为 setTimeout 里的代码会马上执行
  • TypeScript 全用 any，等于没加类型
  • 跨域问题瞎猜，不知道是浏览器的同源策略
