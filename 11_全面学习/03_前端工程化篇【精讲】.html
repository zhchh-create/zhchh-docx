构建工具 Vite/Webpack

构建工具把源码（ES模块、JSX、TS、CSS）打包成浏览器能跑的静态资源。Vite 是现代选择，开发快、配置简单。

  • Webpack：依赖图 + loader + plugin，生态成熟但配置复杂
  • Vite：原生 ESM 开发服务器，构建用 Rollup
  • 核心概念：入口、输出、loader（转译）、plugin（扩展）
// vite.config.js
export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': '/src'
    }
  },
  server: {
    port: 3000,
    proxy: {
      '/api': 'http://localhost:8080'
    }
  }
});

Git 版本控制

Git 是分布式版本控制系统。核心是：每次提交都是一棵可追溯的快照，分支是指向提交的轻量指针。

  • 工作区 → 暂存区 → 本地仓库：add/commit 流程
  • 分支：轻量指针，切分支很快
  • 合并：merge（保留历史）vs rebase（变基，线性历史）
  • 团队协作：feature 分支 → PR → 代码评审 → 合并主干
# 常用工作流
git checkout -b feature/login  # 新建分支
git add .                       # 暂存
git commit -m 'feat: 登录功能'   # 提交
git push origin feature/login  # 推送
# 提 PR，评审通过后合并

代码规范 ESLint + Prettier

ESLint 管代码质量（有没有错误），Prettier 管代码格式（好不好看）。两者配合，统一团队风格。

  • ESLint：静态检查，发现潜在 bug 和坏味道
  • Prettier：格式化工具，统一缩进/引号/分号
  • 配合方式：ESLint 负责质量，Prettier 负责格式，不冲突
  • 提交时自动检查：husky + lint-staged
// .eslintrc.js
module.exports = {
  extends: [
    'eslint:recommended',
    'plugin:vue/vue3-recommended',
    '@vue/eslint-config-prettier'
  ],
  rules: {
    'vue/multi-word-component-names': 'off'
  }
};

前端性能优化

性能优化核心是：减少加载体积、减少渲染次数、提升响应速度。

  • 加载优化：代码分割、懒加载、Tree Shaking、压缩
  • 渲染优化：虚拟列表、懒加载、避免重排重绘
  • 缓存策略：hash 文件名 + 长缓存、HTML 不缓存
  • 监控：Web Vitals（LCP/FID/CLS）
