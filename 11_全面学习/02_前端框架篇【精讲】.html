2核心技术点精讲

Vue 响应式原理

Vue 用数据驱动视图：你只改数据，框架负责更新界面。Vue2 用 Object.defineProperty，Vue3 用 Proxy。

  • 响应式：数据变化自动触发视图更新
  • Vue2：Object.defineProperty 劫持属性 getter/setter
  • Vue3：Proxy 代理整个对象，支持数组和新增属性
  • 模板编译：把模板编译成 render 函数
const state = reactive({
  count: 0,
  user: { name: '张三' }
});

// 自动追踪依赖，变化自动更新视图
state.count++;
state.user.name = '李四';

组件化与通信

组件是 Vue 的核心组织方式：把页面拆成独立、可复用的组件，通过 props/emit/store 通信。

  • props：父传子，单向数据流
  • emit：子传父，触发事件
  • provide/inject：跨层级传值
  • vuex/pinia：全局状态管理

状态管理 Pinia

Pinia 是 Vue 官方推荐的状态管理库，替代 Vuex。简单、类型安全、支持组合式 API。

  • Store 是一个独立的状态容器
  • state：状态数据
  • getters：计算属性，派生状态
  • actions：修改状态的方法
// stores/user.js
import { defineStore } from "pinia"

export const useUserStore = defineStore("user", () => {
  const user = ref(null);
  const isLogin = computed(() => !!user.value);
  
  function login(userData) {
    user.value = userData;
  }
  
  return { user, isLogin, login };
});

// 组件中使用
const userStore = useUserStore();
userStore.login({ name: "张三" });

React Hooks

React 用 Hooks 让函数组件也能拥有状态和生命周期。核心是 useState/useEffect/useMemo。

  • useState：组件状态
  • useEffect：副作用，模拟生命周期
  • useMemo/useCallback：性能优化，缓存计算结果
  • 自定义 Hook：复用状态逻辑

微前端架构

微前端是把大型应用拆成多个独立的子应用，每个子应用可以独立开发、独立部署、独立技术栈。

  • 基座应用：管理子应用加载、路由切换
  • 子应用：独立开发、独立部署
  • JS 沙箱：隔离全局变量，避免污染
  • 样式隔离：避免子应用样式互相影响
// 基座应用注册子应用
registerApp([
  {
    name: "app1",
    entry: "//localhost:3001",
    container: "#sub-container",
    activeRule: "/app1"
  },
  {
    name: "app2",
    entry: "//localhost:3002",
    container: "#sub-container",
    activeRule: "/app2"
  }
]);

4常见误区与实战要点

常见误区：
  • 把状态都放在全局 store，导致状态混乱，难以追踪
  • React useEffect 依赖数组写错，导致无限循环
  • 组件通信层级太深，props 一层层传，变成 props drilling
  • 微前端上了但没用好，反而增加了复杂度
