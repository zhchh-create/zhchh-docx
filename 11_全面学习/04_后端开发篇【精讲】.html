Java 基础与 JVM

Java 是后端最常用的语言之一。核心概念：JVM 内存模型、GC 垃圾回收、并发编程。

  • JVM 内存：堆、栈、方法区、程序计数器
  • GC：可达性分析、垃圾回收算法、收集器
  • 并发：线程池、synchronized、volatile、并发工具
  • 集合框架：ArrayList/HashMap/ConcurrentHashMap
// 线程池示例
ExecutorService pool = Executors.newFixedThreadPool(10);

// 提交任务
Future future = pool.submit(() -> {
  return "处理完成";
});

// 获取结果
String result = future.get();

Spring 核心：IOC 与 AOP

Spring 的两大核心：IOC（控制反转）管理对象生命周期，AOP（面向切面）做横切逻辑。

  • IOC：对象不用自己 new，交给 Spring 容器管理
  • DI：依赖注入，需要什么就注入什么
  • AOP：把日志、事务、权限这些横切逻辑抽出来
  • Bean 生命周期：实例化 → 属性注入 → 初始化 → 销毁
// 定义 Service
@Service
public class UserService {
  @Autowired  // 依赖注入
  private UserMapper userMapper;
  
  public User getUser(Long id) {
    return userMapper.selectById(id);
  }
}

// AOP 示例：日志切面
@Aspect
@Component
public class LogAspect {
  @Around("execution(* com.example.service.*.*(..))")
  public Object log(ProceedingJoinPoint pjp) throws Throwable {
    long start = System.currentTimeMillis();
    Object result = pjp.proceed();
    long cost = System.currentTimeMillis() - start;
    log.info("方法执行耗时: {}", cost);
    return result;
  }
}

SpringBoot 快速开发

SpringBoot 是 Spring 的封装，约定大于配置，开箱即用。内嵌服务器，不用部署 war 包。

  • 自动配置：根据依赖自动配置 Spring
  • Starter：起步依赖，一站式引入所需组件
  • 内嵌 Tomcat：直接 main 方法启动
  • Actuator：监控端点，健康检查、指标采集
@SpringBootApplication
public class Application {
  public static void main(String[] args) {
    SpringApplication.run(Application.class, args);
  }
}

// REST 接口
@RestController
@RequestMapping("/api/users")
public class UserController {
  @GetMapping("/{id}")
  public User getUser(@PathVariable Long id) {
    return userService.getUser(id);
  }
}

MyBatis 持久层

MyBatis 是半自动 ORM：SQL 自己写，结果集自己映射。比 JPA 更灵活，复杂 SQL 好控制。

  • SqlSession：会话，执行 SQL 的入口
  • 动态 SQL：if/choose/foreach，拼接灵活
  • #{} vs ${}：#{} 预编译防注入，${} 直接拼接
  • 一级缓存/SQLSession 级，二级缓存/Mapper 级

接口安全：JWT 与鉴权

JWT 是无状态的鉴权方案：服务端签发 token，客户端每次请求带 token，服务端验证。

  • JWT 结构：Header.Payload.Signature
  • 认证：登录成功返回 token
  • 鉴权：拦截器验证 token，判断权限
  • 刷新 token：access token 短期，refresh token 长期
// 登录签发 token
@PostMapping("/login")
public Result login(@RequestBody LoginDTO dto) {
  User user = userService.login(dto);
  String token = JwtUtil.create({
    "userId": user.getId(),
    "username": user.getName()
  });
  return Result.ok().put("token", token);
}

// 拦截器验证
public class JwtInterceptor implements HandlerInterceptor {
  public boolean preHandle(...) {
    String token = request.getHeader("Authorization");
    return JwtUtil.verify(token); // 验证通过放行
  }
}

4常见误区与实战要点

常见误区：
  • Spring 注入全用字段注入，不好测试，应该用构造器注入
  • MyBatis 用 ${} 而不是 #{}，导致 SQL 注入漏洞
  • JWT 存在 localStorage，容易被 XSS 偷
  • 事务加错地方，以为加了 @Transactional 就万事大吉
